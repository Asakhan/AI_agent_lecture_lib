전체 프로젝트 코드를 리뷰하고 리팩토링해주세요.
먼저 프로젝트 전체 파일을 훑어본 뒤 진행해주세요.

[체크리스트]
1. 코드 중복 제거
2. 함수/메서드 길이 적정성
3. 변수명 명확성
4. import 정리 (사용하지 않는 것 제거)
5. PEP 8 스타일 가이드 준수
6. 성능 최적화 가능 지점

[진행 방식]
1. 먼저 발견한 개선 사항을 우선순위(High/Medium/Low)와 함께 목록으로 제시
2. 중요한 것부터 순서대로 적용
3. 적용 후 `python -m py_compile`과 `pytest tests/ -v`를 다시 실행해
   리팩토링이 기존 동작을 깨지 않았는지 확인
   (가능하면 flake8 또는 ruff로 PEP 8 위반도 점검)
